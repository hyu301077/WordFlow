# WordFlow（词流）

英语词汇学习程序。界面在 `frontend`，服务器代码放在 `backend`。

| 目录 | 内容 |
| --- | --- |
| [frontend](frontend) | Windows 桌面客户端。安装、启动和打包见 [使用说明](frontend/使用说明.md)。 |
| [backend](backend) | 以后的账号、同步和词典服务。现在还没有可运行的服务器。 |

学习记录仍保存在本机的 `%LOCALAPPDATA%\WordFlow`，不放进这两个目录。

从 `frontend` 启动：

```powershell
.\scripts\run.ps1
```
